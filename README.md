# Frontline Hiring Agent: prototypes

- `index.html`: recruiter/admin view inside the HR platform (Applications, Agent runs, Settings, Audit trail)
- `ai-trail.html`: opens the Audit trail (auditor view)
- `candidate.html`: candidate experience on WhatsApp/SMS
- `walkthrough.html`: guided 5-step walkthrough (older version)
- `D1_Decision_Brief.pdf`, `D2_Build_Sheet.pdf`

Static HTML/CSS/JS, no build step. All applicant data is made up.
